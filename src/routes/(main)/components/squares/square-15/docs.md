## Square 15 (Square 15) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-15.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-15.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-15.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-15.json
```

## Usage

```svelte
<script lang="ts">
  import Square15 from "$lib/components/loaders/square/square-15.svelte";
</script>

<Square15 />
```
