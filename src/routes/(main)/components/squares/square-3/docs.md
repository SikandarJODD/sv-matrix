## Square 3 (Square 3) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-3.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-3.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-3.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-3.json
```

## Usage

```svelte
<script lang="ts">
  import Square3 from "$lib/components/loaders/square/square-3.svelte";
</script>

<Square3 />
```
