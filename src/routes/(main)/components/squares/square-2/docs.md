## Square 2 (Square 2) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-2.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-2.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-2.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-2.json
```

## Usage

```svelte
<script lang="ts">
	import Square2 from '$lib/components/loaders/square/square-2.svelte';
</script>

<Square2 />
```
