## Square 1 ( Neon Drift ) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-1.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-1.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-1.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-1.json
```

## Usage

```svelte
<script lang="ts">
    import { Square1 } from '$lib/components/squares/square-1';
</script>

<Square1 />
```
