## Square 5 (Square 5) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-5.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-5.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-5.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-5.json
```

## Usage

```svelte
<script lang="ts">
	import Square5 from '$lib/components/loaders/square/square-5.svelte';
</script>

<Square5 />
```
