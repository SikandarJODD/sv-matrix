## Square 16 (Square 16) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-16.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-16.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-16.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-16.json
```

## Usage

```svelte
<script lang="ts">
  import Square16 from "$lib/components/loaders/square/square-16.svelte";
</script>

<Square16 />
```
