## Square 6 (Square 6) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-6.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-6.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-6.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-6.json
```

## Usage

```svelte
<script lang="ts">
  import Square6 from "$lib/components/loaders/square/square-6.svelte";
</script>

<Square6 />
```
