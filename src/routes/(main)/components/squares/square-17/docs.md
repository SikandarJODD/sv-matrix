## Square 17 (Square 17) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-17.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-17.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-17.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-17.json
```

## Usage

```svelte
<script lang="ts">
	import Square17 from '$lib/components/loaders/square/square-17.svelte';
</script>

<Square17 />
```
