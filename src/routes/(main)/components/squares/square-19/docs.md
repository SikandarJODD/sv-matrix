## Square 19 (Lemniscate Pulse) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-19.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-19.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-19.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-19.json
```

## Usage

```svelte
<script lang="ts">
	import Square19 from '$lib/components/loaders/square/square-19.svelte';
</script>

<Square19 />
```
