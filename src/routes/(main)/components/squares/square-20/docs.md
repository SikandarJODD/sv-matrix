## Square 20 (Mobius Ring) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-20.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-20.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-20.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-20.json
```

## Usage

```svelte
<script lang="ts">
	import Square20 from '$lib/components/loaders/square/square-20.svelte';
</script>

<Square20 />
```
