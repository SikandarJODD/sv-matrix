## Square 7 (Square 7) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-7.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-7.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-7.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-7.json
```

## Usage

```svelte
<script lang="ts">
	import Square7 from '$lib/components/loaders/square/square-7.svelte';
</script>

<Square7 />
```
