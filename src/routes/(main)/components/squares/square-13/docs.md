## Square 13 (Square 13) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-13.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-13.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-13.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-13.json
```

## Usage

```svelte
<script lang="ts">
  import Square13 from "$lib/components/loaders/square/square-13.svelte";
</script>

<Square13 />
```
