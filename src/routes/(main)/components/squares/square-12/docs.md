## Square 12 (Square 12) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-12.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-12.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-12.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-12.json
```

## Usage

```svelte
<script lang="ts">
  import Square12 from "$lib/components/loaders/square/square-12.svelte";
</script>

<Square12 />
```
