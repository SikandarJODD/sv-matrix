## Square 10 (Square 10) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-10.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-10.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-10.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-10.json
```

## Usage

```svelte
<script lang="ts">
	import Square10 from '$lib/components/loaders/square/square-10.svelte';
</script>

<Square10 />
```
