## Square 14 (Square 14) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-14.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-14.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-14.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-14.json
```

## Usage

```svelte
<script lang="ts">
  import Square14 from "$lib/components/loaders/square/square-14.svelte";
</script>

<Square14 />
```
