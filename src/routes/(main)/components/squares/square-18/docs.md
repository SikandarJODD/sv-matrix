## Square 18 (Square 18) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-18.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-18.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-18.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-18.json
```

## Usage

```svelte
<script lang="ts">
  import Square18 from "$lib/components/loaders/square/square-18.svelte";
</script>

<Square18 />
```
