## Square 9 (Square 9) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-9.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-9.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-9.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-9.json
```

## Usage

```svelte
<script lang="ts">
	import Square9 from '$lib/components/loaders/square/square-9.svelte';
</script>

<Square9 />
```
