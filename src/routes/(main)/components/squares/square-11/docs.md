## Square 11 (Square 11) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-11.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-11.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-11.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-11.json
```

## Usage

```svelte
<script lang="ts">
	import Square11 from '$lib/components/loaders/square/square-11.svelte';
</script>

<Square11 />
```
