## Square 4 (Square 4) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-4.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/square-4.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/square-4.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/square-4.json
```

## Usage

```svelte
<script lang="ts">
	import Square4 from '$lib/components/loaders/square/square-4.svelte';
</script>

<Square4 />
```
