## Triangle 2 (Triangle 2) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-2.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-2.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-2.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-2.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle2 from '$lib/components/loaders/triangle/triangle-2.svelte';
</script>

<Triangle2 />
```
