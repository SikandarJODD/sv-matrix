## Triangle 17 (Triangle 17) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-17.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-17.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-17.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-17.json
```

## Usage

```svelte
<script lang="ts">
  import Triangle17 from "$lib/components/loaders/triangle/triangle-17.svelte";
</script>

<Triangle17 />
```
