## Triangle 1 (Triangle 1) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-1.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-1.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-1.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-1.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle1 from '$lib/components/loaders/triangle/triangle-1.svelte';
</script>

<Triangle1 />
```
