## Triangle 6 (Triangle 6) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-6.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-6.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-6.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-6.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle6 from '$lib/components/loaders/triangle/triangle-6.svelte';
</script>

<Triangle6 />
```
