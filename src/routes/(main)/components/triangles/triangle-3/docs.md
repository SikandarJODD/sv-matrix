## Triangle 3 (Triangle 3) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-3.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-3.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-3.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-3.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle3 from '$lib/components/loaders/triangle/triangle-3.svelte';
</script>

<Triangle3 />
```
