## Triangle 11 (Triangle 11) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-11.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-11.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-11.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-11.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle11 from '$lib/components/loaders/triangle/triangle-11.svelte';
</script>

<Triangle11 />
```
