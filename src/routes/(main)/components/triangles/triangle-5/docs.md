## Triangle 5 (Triangle 5) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-5.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-5.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-5.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-5.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle5 from '$lib/components/loaders/triangle/triangle-5.svelte';
</script>

<Triangle5 />
```
