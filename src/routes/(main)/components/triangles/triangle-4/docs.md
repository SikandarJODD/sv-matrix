## Triangle 4 (Triangle 4) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-4.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-4.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-4.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-4.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle4 from '$lib/components/loaders/triangle/triangle-4.svelte';
</script>

<Triangle4 />
```
