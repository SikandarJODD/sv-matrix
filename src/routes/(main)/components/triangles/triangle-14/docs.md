## Triangle 14 (Triangle 14) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-14.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-14.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-14.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-14.json
```

## Usage

```svelte
<script lang="ts">
  import Triangle14 from "$lib/components/loaders/triangle/triangle-14.svelte";
</script>

<Triangle14 />
```
