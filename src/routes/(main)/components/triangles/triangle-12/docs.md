## Triangle 12 (Triangle 12) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-12.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-12.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-12.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-12.json
```

## Usage

```svelte
<script lang="ts">
  import Triangle12 from "$lib/components/loaders/triangle/triangle-12.svelte";
</script>

<Triangle12 />
```
