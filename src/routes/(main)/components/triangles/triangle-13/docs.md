## Triangle 13 (Triangle 13) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-13.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-13.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-13.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-13.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle13 from '$lib/components/loaders/triangle/triangle-13.svelte';
</script>

<Triangle13 />
```
