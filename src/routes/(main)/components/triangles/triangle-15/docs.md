## Triangle 15 (Triangle 15) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-15.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-15.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-15.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-15.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle15 from '$lib/components/loaders/triangle/triangle-15.svelte';
</script>

<Triangle15 />
```
