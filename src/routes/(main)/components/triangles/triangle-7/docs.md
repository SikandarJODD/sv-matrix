## Triangle 7 (Triangle 7) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-7.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-7.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-7.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-7.json
```

## Usage

```svelte
<script lang="ts">
  import Triangle7 from "$lib/components/loaders/triangle/triangle-7.svelte";
</script>

<Triangle7 />
```
