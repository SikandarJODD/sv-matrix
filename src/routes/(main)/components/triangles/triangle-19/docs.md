## Triangle 19 (Triangle 19) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-19.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-19.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-19.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-19.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle19 from '$lib/components/loaders/triangle/triangle-19.svelte';
</script>

<Triangle19 />
```
