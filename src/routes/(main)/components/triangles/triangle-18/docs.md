## Triangle 18 (Triangle 18) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-18.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-18.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-18.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-18.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle18 from '$lib/components/loaders/triangle/triangle-18.svelte';
</script>

<Triangle18 />
```
