## Triangle 9 (Triangle 9) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-9.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-9.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-9.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-9.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle9 from '$lib/components/loaders/triangle/triangle-9.svelte';
</script>

<Triangle9 />
```
