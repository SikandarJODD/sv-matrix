## Triangle 16 (Triangle 16) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-16.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-16.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-16.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-16.json
```

## Usage

```svelte
<script lang="ts">
  import Triangle16 from "$lib/components/loaders/triangle/triangle-16.svelte";
</script>

<Triangle16 />
```
