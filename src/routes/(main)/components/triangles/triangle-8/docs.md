## Triangle 8 (Triangle 8) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-8.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-8.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-8.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-8.json
```

## Usage

```svelte
<script lang="ts">
  import Triangle8 from "$lib/components/loaders/triangle/triangle-8.svelte";
</script>

<Triangle8 />
```
