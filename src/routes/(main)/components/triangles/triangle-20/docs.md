## Triangle 20 (Triangle 20) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-20.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/triangle-20.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/triangle-20.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/triangle-20.json
```

## Usage

```svelte
<script lang="ts">
	import Triangle20 from '$lib/components/loaders/triangle/triangle-20.svelte';
</script>

<Triangle20 />
```
