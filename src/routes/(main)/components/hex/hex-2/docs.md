## Hex 2 (Hex 2) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-2.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-2.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/hex-2.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/hex-2.json
```

## Usage

```svelte
<script lang="ts">
  import Hex2 from "$lib/components/loaders/hex/hex-2.svelte";
</script>

<Hex2 />
```
