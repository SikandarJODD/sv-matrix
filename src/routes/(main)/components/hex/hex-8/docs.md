## Hex 8 (Hex 8) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-8.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-8.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/hex-8.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/hex-8.json
```

## Usage

```svelte
<script lang="ts">
  import Hex8 from "$lib/components/loaders/hex/hex-8.svelte";
</script>

<Hex8 />
```
