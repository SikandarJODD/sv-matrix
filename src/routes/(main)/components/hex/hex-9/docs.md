## Hex 9 (Hex 9) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-9.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-9.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/hex-9.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/hex-9.json
```

## Usage

```svelte
<script lang="ts">
  import Hex9 from "$lib/components/loaders/hex/hex-9.svelte";
</script>

<Hex9 />
```
