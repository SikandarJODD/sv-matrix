## Hex 10 (Hex 10) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-10.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-10.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/hex-10.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/hex-10.json
```

## Usage

```svelte
<script lang="ts">
  import Hex10 from "$lib/components/loaders/hex/hex-10.svelte";
</script>

<Hex10 />
```
