## Hex 3 (Hex 3) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-3.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-3.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/hex-3.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/hex-3.json
```

## Usage

```svelte
<script lang="ts">
  import Hex3 from "$lib/components/loaders/hex/hex-3.svelte";
</script>

<Hex3 />
```
