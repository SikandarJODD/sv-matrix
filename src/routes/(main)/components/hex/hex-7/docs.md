## Hex 7 (Hex 7) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-7.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-7.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/hex-7.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/hex-7.json
```

## Usage

```svelte
<script lang="ts">
  import Hex7 from "$lib/components/loaders/hex/hex-7.svelte";
</script>

<Hex7 />
```
