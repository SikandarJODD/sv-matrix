## Hex 4 (Hex 4) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-4.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-4.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/hex-4.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/hex-4.json
```

## Usage

```svelte
<script lang="ts">
  import Hex4 from "$lib/components/loaders/hex/hex-4.svelte";
</script>

<Hex4 />
```
