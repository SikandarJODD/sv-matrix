## Hex 1 (Hex 1) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-1.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-1.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/hex-1.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/hex-1.json
```

## Usage

```svelte
<script lang="ts">
  import Hex1 from "$lib/components/loaders/hex/hex-1.svelte";
</script>

<Hex1 />
```
