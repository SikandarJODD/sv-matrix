## Hex 6 (Hex 6) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-6.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/hex-6.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/hex-6.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/hex-6.json
```

## Usage

```svelte
<script lang="ts">
  import Hex6 from "$lib/components/loaders/hex/hex-6.svelte";
</script>

<Hex6 />
```
