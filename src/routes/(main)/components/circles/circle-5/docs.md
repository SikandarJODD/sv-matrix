## Circle 5 (Circle 5) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-5.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-5.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-5.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-5.json
```

## Usage

```svelte
<script lang="ts">
	import Circle5 from '$lib/components/loaders/circles/circle-5.svelte';
</script>

<Circle5 />
```
