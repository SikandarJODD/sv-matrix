## Circle 3 (Circle 3) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-3.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-3.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-3.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-3.json
```

## Usage

```svelte
<script lang="ts">
	import Circle3 from '$lib/components/loaders/circles/circle-3.svelte';
</script>

<Circle3 />
```
