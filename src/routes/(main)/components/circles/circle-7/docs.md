## Circle 7 (Circle 7) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-7.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-7.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-7.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-7.json
```

## Usage

```svelte
<script lang="ts">
	import Circle7 from '$lib/components/loaders/circles/circle-7.svelte';
</script>

<Circle7 />
```
