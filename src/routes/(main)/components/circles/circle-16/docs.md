## Circle 16 (Circle 16) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-16.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-16.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-16.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-16.json
```

## Usage

```svelte
<script lang="ts">
	import Circle16 from '$lib/components/loaders/circles/circle-16.svelte';
</script>

<Circle16 />
```
