## Circle 20 (Circle 20) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-20.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-20.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-20.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-20.json
```

## Usage

```svelte
<script lang="ts">
  import Circle20 from "$lib/components/loaders/circles/circle-20.svelte";
</script>

<Circle20 />
```
