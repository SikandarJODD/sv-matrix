## Circle 19 (Circle 19) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-19.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-19.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-19.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-19.json
```

## Usage

```svelte
<script lang="ts">
  import Circle19 from "$lib/components/loaders/circles/circle-19.svelte";
</script>

<Circle19 />
```
