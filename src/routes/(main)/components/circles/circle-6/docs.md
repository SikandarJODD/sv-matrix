## Circle 6 (Circle 6) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-6.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-6.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-6.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-6.json
```

## Usage

```svelte
<script lang="ts">
	import Circle6 from '$lib/components/loaders/circles/circle-6.svelte';
</script>

<Circle6 />
```
