## Circle 10 (Circle 10) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-10.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-10.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-10.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-10.json
```

## Usage

```svelte
<script lang="ts">
	import Circle10 from '$lib/components/loaders/circles/circle-10.svelte';
</script>

<Circle10 />
```
