## Circle 14 (Circle 14) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-14.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-14.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-14.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-14.json
```

## Usage

```svelte
<script lang="ts">
	import Circle14 from '$lib/components/loaders/circles/circle-14.svelte';
</script>

<Circle14 />
```
