## Circle 9 (Circle 9) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-9.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-9.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-9.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-9.json
```

## Usage

```svelte
<script lang="ts">
  import Circle9 from "$lib/components/loaders/circles/circle-9.svelte";
</script>

<Circle9 />
```
