## Circle 2 (Circle 2) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-2.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-2.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-2.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-2.json
```

## Usage

```svelte
<script lang="ts">
  import Circle2 from "$lib/components/loaders/circles/circle-2.svelte";
</script>

<Circle2 />
```
