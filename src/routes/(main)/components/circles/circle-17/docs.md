## Circle 17 (Circle 17) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-17.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-17.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-17.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-17.json
```

## Usage

```svelte
<script lang="ts">
	import Circle17 from '$lib/components/loaders/circles/circle-17.svelte';
</script>

<Circle17 />
```
