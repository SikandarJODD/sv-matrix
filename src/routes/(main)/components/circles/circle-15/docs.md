## Circle 15 (Circle 15) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-15.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-15.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-15.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-15.json
```

## Usage

```svelte
<script lang="ts">
  import Circle15 from "$lib/components/loaders/circles/circle-15.svelte";
</script>

<Circle15 />
```
