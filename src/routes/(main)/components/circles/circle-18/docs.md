## Circle 18 (Circle 18) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-18.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-18.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-18.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-18.json
```

## Usage

```svelte
<script lang="ts">
  import Circle18 from "$lib/components/loaders/circles/circle-18.svelte";
</script>

<Circle18 />
```
