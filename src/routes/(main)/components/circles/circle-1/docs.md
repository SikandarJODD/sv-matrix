## Circle 1 (Circle 1) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-1.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-1.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-1.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-1.json
```

## Usage

```svelte
<script lang="ts">
  import Circle1 from "$lib/components/loaders/circles/circle-1.svelte";
</script>

<Circle1 />
```
