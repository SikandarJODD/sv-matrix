## Circle 12 (Circle 12) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-12.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-12.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-12.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-12.json
```

## Usage

```svelte
<script lang="ts">
	import Circle12 from '$lib/components/loaders/circles/circle-12.svelte';
</script>

<Circle12 />
```
