## Circle 11 (Circle 11) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-11.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-11.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-11.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-11.json
```

## Usage

```svelte
<script lang="ts">
  import Circle11 from "$lib/components/loaders/circles/circle-11.svelte";
</script>

<Circle11 />
```
