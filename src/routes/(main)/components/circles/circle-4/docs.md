## Circle 4 (Circle 4) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-4.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-4.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-4.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-4.json
```

## Usage

```svelte
<script lang="ts">
  import Circle4 from "$lib/components/loaders/circles/circle-4.svelte";
</script>

<Circle4 />
```
