## Circle 8 (Circle 8) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-8.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-8.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-8.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-8.json
```

## Usage

```svelte
<script lang="ts">
  import Circle8 from "$lib/components/loaders/circles/circle-8.svelte";
</script>

<Circle8 />
```
