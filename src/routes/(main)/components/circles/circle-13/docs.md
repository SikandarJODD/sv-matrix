## Circle 13 (Circle 13) Loader

## Installation

npm

```bash
npx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-13.json
```

pnpm

```bash
pnpm dlx shadcn-svelte@latest add https://sv-matrix.vercel.app/r/circle-13.json
```

yarn

```bash
npx shadcn-svelte@latest add http://localhost:5173/r/circle-13.json
```

bun

```bash
bun x shadcn-svelte@latest add http://localhost:5173/r/circle-13.json
```

## Usage

```svelte
<script lang="ts">
	import Circle13 from '$lib/components/loaders/circles/circle-13.svelte';
</script>

<Circle13 />
```
